# Magisk Alist 模块 - 操作按钮与实时控制 PRD

## 概述
为 Magisk Alist 模块添加 Magisk 原生"操作"按钮（类似 LSPosed IT 模块），点击后弹出交互菜单，支持用音量键选择打开/关闭 Alist 服务，操作即时生效无需重启，并在模块介绍区域实时显示运行状态。

## 目标
1. 在模块卡片上显示"操作"按钮（通过 module.prop 的 action=1 实现）
2. 点击"操作"后弹出 ui_ask 交互菜单，支持音量键导航
3. 根据当前运行状态动态显示不同选项：
   - 运行中：显示"关闭模块"和"退出选择界面"
   - 已停止：显示"打开模块"和"退出选择界面"
4. 打开/关闭操作即时生效，无需重启手机
5. 模块介绍区域实时显示运行状态（运行中/已停止）
6. 关闭时看门狗不再自动重启，手动开启后恢复守护

## 非目标
- 不修改 Alist 本身的核心功能
- 不添加 Web UI 之外的远程控制方式
- 不添加定时开关功能
- 不改变开机自启行为

## 功能需求

### FR-1: 操作按钮（action=1）
- module.prop 添加 action=1 字段，Magisk 自动显示"操作"按钮
- 点击按钮时 Magisk 执行模块根目录的 action.sh

### FR-2: 交互式菜单（ui_ask）
- action.sh 启动时检测当前 Alist 运行状态
- 运行中：ui_ask 显示 "AList运行中" + "关闭模块" + "退出选择界面"
- 已停止：ui_ask 显示 "AList已停止" + "打开模块" + "退出选择界面"
- 支持音量键上下选择，电源键确认

### FR-3: 即时开关
- 关闭：创建 `.paused` 暂停标记 + kill alist 进程（端口立即释放）
- 打开：删除 `.paused` + 重新启动 alist（端口立即监听）
- 均无需重启手机

### FR-4: 看门狗暂停机制
- 新增 `.paused` 文件作为暂停标记
- 看门狗循环检查 `.paused`，存在时跳过重启逻辑
- 手动开启时删除 `.paused`，看门狗恢复正常守护

### FR-5: 实时状态显示
- 动态更新 module.prop 的 description 字段，在标题后追加状态标签
- 运行中：description 末尾追加 " | 运行中"
- 已停止：description 末尾追加 " | 已停止"
- 开机时自动检测状态并更新

### FR-6: 启动逻辑分离
- start_alist.sh 分离为：一次性初始化 + 启动函数 + 看门狗循环
- 启动函数可被 action.sh 调用，实现手动开启
- 初始化逻辑（MODDIR 检测、busybox 查找、chmod、wake_lock、data 目录、admin 初始化）只执行一次

## 非功能需求

- **兼容性**：兼容正式版 + alpha 版 Magisk，Android 10+
- **响应速度**：关闭操作 2 秒内完成，打开操作 5 秒内完成
- **可靠性**：手动关闭后看门狗不会误重启；手动开启后看门狗正常守护
